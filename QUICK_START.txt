## Como começar:

1. **Clonar/Acessar projeto:**
   cd C:/Users/User/Cooplist

2. **Configurar Spotify:**
   - Acesse https://developer.spotify.com/dashboard
   - Crie uma aplicação
   - Copie Client ID e Client Secret

3. **Iniciar Docker:**
   docker run -p 3000:3000 \
     -e SPOTIFY_CLIENT_ID=seu_id \
     -e SPOTIFY_CLIENT_SECRET=seu_secret \
     cooplist:latest

4. **Acessar:**
   http://localhost:3000
