### 3. CI/CD Pipeline ✅

**Arquivo:** `.github/workflows/ci-cd.yml`

**Stages:**

#### 1. Lint (Verificação de Código)
```yaml
- TypeScript type check
- Verifica erros de tipo
- Falha se houver problemas
```

#### 2. Tests (Testes Automatizados)
```yaml
- npm ci (instalar deps)
- npm test (rodar testes)
- npm run test:coverage (gerar coverage)
- Upload para Codecov
```

#### 3. Build Docker
```yaml
- Setup Docker Buildx
- Build image: cooplist:${{ github.sha }}
- Cache para velocidade
```

#### 4. Security Scan
```yaml
- npm audit (verificar vulnerabilidades)
- Level: moderate
- Não falha a build
```

#### 5. Deploy (apenas main)
```yaml
- Executado só em push para main
- Pronto para adicionar steps de deploy
- Railway / Vercel integration
```

**Triggers:**
```yaml
- Push em: main, master, develop
- Pull Request em: main, master, develop
```
