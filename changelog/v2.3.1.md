## ✅ 5 Features Implementadas

### 1. Validação de Duplicatas de Músicas ✅

**Implementação:**
- Playlist não pode ter a mesma música duas vezes
- Verificação por `spotify_track_id`
- Erro 400: "This song is already in the playlist"

**Código:**
```typescript
// src/routes/songs.ts
const existingSong = await db.get(
  'SELECT id FROM playlist_songs WHERE playlist_id = ? AND spotify_track_id = ?',
  [playlistId, spotify_track_id]
);

if (existingSong) {
  res.status(400).json({ error: 'This song is already in the playlist' });
  return;
}
```

**Benefício:** Evita duplicatas, mantém fila limpa

### 2. Sistema de Convites Melhorado ✅

**Implementação:**

#### Reutilizável
- Link pode ser usado múltiplas vezes (até limite)
- Campo `max_uses` opcional
- Campo `uses` rastreia número de vezes

#### Deletável
- Admin/Moderator podem deletar convites
- Novo endpoint: `DELETE /:playlistId/invites/:inviteId`
- Revogar acesso imediatamente

**Endpoints:**
```
POST   /api/playlists/:id/invite-link    # Gerar link (reutilizável)
POST   /api/playlists/:id/invite-email   # Email invite
POST   /accept/:token                    # Aceitar (sem consumir se max_uses)
GET    /api/playlists/:id/invites        # Listar (admin/mod)
DELETE /api/playlists/:id/invites/:id    # Deletar/Revogar
```

**Request Body (criar link):**
```json
{
  "role": "user",
  "expiresIn": 7,
  "maxUses": 5  // null = ilimitado
}
```

### 3. Remoção vs Banimento Separados ✅

**Antes:** Remover = Banir permanente  
**Depois:** 2 ações distintas

#### Remover (sem banir)
- `DELETE /api/playlists/:id/members/:memberId`
- Membro sai da playlist
- Pode entrar novamente (via convite)
- Removido de `playlist_members`

#### Banir (com bloqueio)
- `POST /api/playlists/:id/members/:memberId/ban`
- Membro é removido
- **Não pode entrar novamente**
- Registro em `playlist_bans` table
- Admin pode debanir: `POST /api/playlists/:id/members/:userId/unban`

**Table `playlist_bans`:**
```sql
CREATE TABLE playlist_bans (
  id INTEGER PRIMARY KEY,
  playlist_id INTEGER NOT NULL,
  user_id INTEGER NOT NULL,
  banned_by INTEGER NOT NULL,
  reason TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(playlist_id, user_id),
  FOREIGN KEY(playlist_id) REFERENCES playlists(id),
  FOREIGN KEY(user_id) REFERENCES users(id)
);
```

**Equivalente para músicas:**
```
DELETE /api/playlists/:id/songs/:songId     # Remove (pode re-adicionar)
POST   /api/playlists/:id/songs/:songId/ban # Ban (bloqueia para sempre)
```

### 5. Criar Playlist no Spotify (Web API) ✅

**Implementação:**

#### Novo Endpoint
- `POST /api/playlists/:playlistId/sync-to-spotify`
- Requer: `spotifyAccessToken` (user's token)
- Cria playlist privada na conta do usuário
- Adiciona todas as músicas da fila

#### Request
```json
{
  "spotifyAccessToken": "user_spotify_token_here"
}
```

#### Response
```json
{
  "message": "Playlist created on Spotify",
  "spotify_playlist": {
    "id": "spotify_id",
    "name": "My Playlist",
    "url": "https://open.spotify.com/playlist/..."
  }
}
```

#### Permissões
- Apenas Admin/Moderator podem fazer sync
- Playlist deve estar local ou em fallback
- Usa Spotify Web API v1

#### Fluxo
1. User (Admin/Mod) clica "Create on Spotify"
2. Frontend abre Spotify OAuth
3. User autoriza
4. Frontend obtém access token
5. POST ao endpoint com token
6. Backend chama Spotify API
7. Playlist criada como PRIVADA
8. Todas as músicas adicionadas
9. Database atualizado com spotify_id

#### Código
```typescript
// src/services/spotifyService.ts
async createPlaylistWithUserToken(
  userAccessToken: string,
  name: string,
  description: string,
  isPublic: boolean = false
): Promise<SpotifyPlaylist> {
  // 1. Obter userId do usuário logado
  const meResponse = await axios.get(`https://api.spotify.com/v1/me`, {
    headers: { Authorization: `Bearer ${userAccessToken}` }
  });
  
  // 2. Criar playlist privada
  const playlistResponse = await axios.post(
    `https://api.spotify.com/v1/users/${userId}/playlists`,
    {
      name,
      description,
      public: isPublic // Privado por padrão
    },
    { headers: { Authorization: `Bearer ${userAccessToken}` } }
  );
  
  return playlistResponse.data;
}
```

**Referência Spotify API:**
- Create Playlist: https://developer.spotify.com/documentation/web-api/reference/create-playlist
- Add Items: https://developer.spotify.com/documentation/web-api/reference/add-items-to-playlist
