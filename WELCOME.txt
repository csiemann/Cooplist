🚀 INICIAR EM 3 PASSOS:

1. Obter credenciais Spotify:
   https://developer.spotify.com/dashboard

2. Executar Docker:
   docker run -p 3000:3000 \
     -e SPOTIFY_CLIENT_ID=seu_id \
     -e SPOTIFY_CLIENT_SECRET=seu_secret \
     cooplist:latest

3. Acessar:
   http://localhost:3000
